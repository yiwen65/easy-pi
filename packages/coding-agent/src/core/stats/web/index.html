    Notes

    • Token classes: input = uncached prompt, cache read / cache write = prompt-cache traffic, output = completion tokens.
    • Cache hit rate = cache read / (input + cache read + cache write).
    • Cost uses the model catalog rates recorded with each message; subscription plans are not discounted and historical prices are not recomputed.
    • Compaction, branch-summary and tool-result usage are included, matching the in-session /session totals.
    • The panel is read-only, binds to 127.0.0.1 and performs no outbound requests.
