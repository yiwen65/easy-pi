## Explicit focused surfaces

A focused editor can be a distinct compositor window with a non-AXWindow root. Discovery supplies optional numeric-identity-derived focus metadata; `focused:true` excludes unknown values. The caller must explicitly select its returned reference. Same PID, geometry overlap or a parent reference never grants the child surface.

General scans verify each element's membership before reading descriptive content. A same-PID child directly mapped to a different window is a scope boundary: neither its content nor descendants are read. Unknown membership still makes the scan incomplete. Foreign roots and legacy strict scans are not silently accepted. This distinction repairs a Chrome regression introduced by treating every foreign branch as unknown membership.
